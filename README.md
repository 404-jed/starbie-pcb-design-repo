# Starbie

## Your own Star-Shaped Digital Pet that you can take care of!

Starbie is a digital pet project built around a custom-designed PCB. Inspired by the original Starbie guide, this project uses electronics, PCB design from Kicad, programming, and pixel art to create a cute interactive partner.

My goal with this project was to personalize the original design and make it my own using designs such as a starshaped PCB, my own artwork, and modifying the original firmware to give it its own personality.

Some features of the Starbie companion include:

- Custom star-shaped PCB: star-shaped board outline
- Interactive controls: buttons for interacting + built in accelerometer
- OLED display: displays the pet + menu
- Enviornmental sensor: Temperature/Humidity
- Artwork: Art on pcb board + sprite designs
- Firmware: changes to original arduino firmware

Software + Tools
- KiCad: Schematic Editor + PCB Editor
- Arduino IDE
- C++
- Canva: Artwork

Lessons Learned

From doing this project, I've gained real-life experience with going through the process of designing a PCB. I learned how to set up KiCad, create footprints and symbols, familiarized myself with C++, and did a lot more. I've also discovered newfound patience, especially when learning a new tool and having to troubleshoot whenever a problem occurs. Although I'm submitting this project soon, I believe that this is still an ongoing project. Later in the future, I plan to improve its firmware and overall design.
